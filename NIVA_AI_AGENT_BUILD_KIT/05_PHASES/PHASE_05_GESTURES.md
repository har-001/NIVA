# Phase 05 — Hand Gesture Recognition

## Objective
Hand tracking, standard/custom gestures, confidence thresholds, air mouse/drawing and draw-a-box recognition.

## Mandatory Procedure
1. Read rules and handover files.
2. Inspect existing code.
3. Write a plan.
4. Implement incrementally.
5. Add/update tests.
6. Run relevant checks.
7. Verify acceptance criteria.
8. Update documentation and handover.

## Acceptance Criteria
- Normal flow works.
- Errors are handled.
- Permissions are respected.
- Critical paths are tested.
- Existing functionality is not broken.
- Documentation is updated.
