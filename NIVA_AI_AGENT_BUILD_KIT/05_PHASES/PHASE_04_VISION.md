# Phase 04 — Vision

## Objective

## Mandatory Procedure
1. Read rules and handover files.
2. Inspect existing code.
3. Write a plan.
4. Implement incrementally.
5. Add/update tests.

7. Verify acceptance criteria.
8. Update documentation and handover.

## Acceptance Criteria
- Normal flow works.
- Errors are handled.
- Permissions are respected.
- Critical paths are tested.
- Existing functionality is not broken.
- Documentation is updated.
