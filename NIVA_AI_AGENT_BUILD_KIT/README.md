# NIVA — Complete AI Agent Build Kit

NIVA (Neural Intelligent Virtual Assistant) is a modular, secure and hostable multimodal personal AI assistant.

## Current Scope
- Web application
- Desktop/trusted local agent
- Hostable backend/API
- Text and voice interaction
- Vision and hand gesture recognition
- Controlled computer actions
- Security
- Memory/RAG
- Image/audio/video/code generation
- Communication
- Automation
- Plugins and multi-agent orchestration

## Future Scope
Native Android and iOS applications are future reference only and must not be implemented now.

## Mandatory Workflow
INSPECT → PLAN → IMPLEMENT → TEST → VERIFY → DOCUMENT → HANDOVER
