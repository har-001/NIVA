# Unified PRD
Goal: one NIVA ecosystem across existing Web, Tauri Desktop and Expo Mobile using shared backend/AI services.

Web: existing app; preserve and integrate.
Desktop: Jarvis UI, voice, PC controls, files, apps/windows, camera, gestures, notifications and safe power controls.
Mobile: chat, voice, auth, notifications, camera, settings, memory and authorized device control.
Backend: auth, AI orchestration, memory/RAG, typed tool registry, authorization, API, streaming/events and audit logging.
