# Required Software

Web: VS Code, Node.js if required, Python if required, Git, browser DevTools.

Tauri Desktop: Node.js, Rust/Cargo, Tauri OS prerequisites, VS Code/IntelliJ, Git, Python if local CV/voice is used.

Backend: Python/FastAPI if needed, existing DB/PostgreSQL, Redis if needed, Docker Desktop, Postman/Insomnia.

Design: Figma.
